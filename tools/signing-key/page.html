ROJINK / ANDROID RELEASE

کلیلی واژۆی ڕۆژئینک

کلیلی تایبەت بە وەشانی Release تەنها لەم براوسەرەدا دروست دەبێت. ئەم ئامرازە هیچ کلیل، وشەی نهێنی یان زانیارییەک نانێرێت.

01 دروستکردنی کلیلی واژۆ

ئەگەر پێشتر وەشانی Release ـت بە کلیلی خۆت واژۆ کردووە، هەمان کلیل بەکاربهێنە و کلیلێکی نوێ دروست مەکە. کلیلی نوێ ناتوانێت ئەپی واژۆکراو بە کلیلی پێشوو نوێ بکاتەوە.

ANDROID_STORE_PASSWORD و ANDROID_KEY_PASSWORD هەمان وشەی نهێنین: ١٢ پیتی هەڕەمەکی.

کلیلم هەیە؛ تەنها وشەی نهێنی کورت بکە

فایلی .p12 یان TXT ـی پێشوو هەڵبژێرە و وشەی نهێنیی پێشوو تەنها لێرە بنووسە. خودی کلیلی واژۆ ناگۆڕدرێت.

02 کۆپیی پارێزراو هەڵبگرە

پێش داخستنی پەڕە، فایلە کۆدکراوەکە و وشەی نهێنییە نوێیەکە لە شوێنێکی پارێزراوی خۆت هەڵبگرە. GitHub Secrets کۆپییەکی گەڕاندنەوە نییە و ناتوانیت بەهاکانی لێ بخوێنیتەوە.

لە TXT ـەکەدا تەنها بەهای ANDROID_KEYSTORE_BASE64 هەیە؛ وشەی نهێنی لە فایلەکەدا نییە.

پەنجەمۆری بڕوانامە — SHA‑256

03 بەهاکان لە گیتهاب دابنێ

لە تابێکی نوێدا پرۆژەکە لە گیتهاب بکەرەوە. لە شوێنی خوارەوە هەر چوار بەهاکە بە جیا زیاد بکە؛ یەک وشەی نهێنی بۆ هەردوو PASSWORD بەکار دێت.

Settings → Secrets and variables → Actions → New repository secret

    کلیل و وشەی نهێنی مەخەرە ناو چات یان کۆدی پرۆژەکە. دوای پاشەکەوتکردن، بەهاکان لەم پەڕەیە و لە لیستی کۆپیی ئامێرەکە بسڕەوە.

    ڕۆژئینک · هیچ زانیارییەک لەم ئامرازەوە نانێردرێت.
