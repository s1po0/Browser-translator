# چۆن خەڵک ووشە ئەنجلۆزییەکانی مانهوا دەکەنە کوردی

گەڕانێکی ورد لە پڕۆژە کراوەکانی وەرگێڕانی کۆمیک (manga / manhwa / webtoon) و لە توێژینەوەکانی زمانی کوردی.
ئەمە ئەنجامی گەڕانەکەیە، لەگەڵ ئەوەی کام شت لە ئێمەدا هەیە و کام شت نەماوە.

---

## ١. شێوازێکی گشتی: هەمووان هەمان چوار قۆناغ بەکاردەهێنن

هەموو ئامرازە جدییەکان — `manga-image-translator` (زیاتر لە ١٠ هەزار ئەستێرە)، `BallonsTranslator`،
`MangaTranslator`، `manga-translator`ی عەرەبی، و `webtoon-translator` — هەمان شەش هەنگاو دەگرن:

| قۆناغ | کردار | مەبەست |
|---|---|---|
| ١ | دۆزینەوەی باڵۆن و دەق | YOLO / RT-DETR ی مەشقپێکراو لەسەر Manga109، یان شێوەی هەندەسی (contour + بازنەی ڕەش) |
| ٢ | خوێندنەوە (OCR) | مۆدێلی تایبەت بە کۆمیک؛ دەقەکانی هەمان باڵۆن **پێش** وەرگێڕان بەیەک دەگەنەوە |
| ٣ | وەرگێڕان | زنجیرەی fallback (Google → deep-translator → MyMemory → LLM) + cache |
| ٤ | سڕینەوە | LaMa inpaint، یان تەنها سڕینی *پیکسلەکانی نووسین* — هونەر دەمێنێت |
| ٥ | نووسینەوە | قەبارەی فۆنت بە binary search، ناوەندکردن لە ناوەوەی باڵۆن، ڕەنگی جیاواز لەسەر پاشبنەمای تاریک/ڕوون |
| ٦ | پشکنین | ئەگەر وەرگێڕان نەگونجا، **بەتاڵ دەهێڵرێت** و وێنەی ڕەسەن دەپارێزرێت، نەک نووسینی سەروپێچ |

**وانەی سەرەکی:** هەموو ئەمانە *دەق* دەخوێننەوە و *دەق* دەنووسنەوە؛ هیچیان «وێنە بۆ وێنە» ناکەن.
واتە: کێشەکە Lens نییە، کێشەکە **دۆزینەوە + خوێندنەوەی دروست** ە.

سەرچاوە:
- [zyddnys/manga-image-translator](https://github.com/zyddnys/manga-image-translator) — detection / OCR / lama_large inpaint / render، `dec_auto_rotate`، `ignore_bubble: 5–10`
- [webtoon-translator](https://github.com/surya758/webtoon-translator) — RT-DETR-v2 comic detector (ONNX, CPU)، سکانی وێنە درێژەکان بە **پەنجەرەی چوارگۆشە**، LaMa بۆ manga
- [manga-translator (عەرەبی)](https://github.com/bababadr06-dot/manga-translator) — Arabic reshaping/bidi، «شێوەکردن تەنها جارێک»، `INPAINT_TEXT_PIXELS_ONLY`
- [manga-translator-cli](https://github.com/zbu1/manga-translator-cli) — YOLOv8m balloons + PaddleOCR-VL + binary search بۆ فۆنت
- [COMICORDA (LREC-COLING 2024)](https://aclanthology.org/2024.lrec-main.316/) — YOLOv8 بۆ باڵۆن، AP ٪٩٨

## ٢. دۆزینەوەی باڵۆن: دوو ڕێگا

**ڕێگای فێربوو:** مۆدێلی segmentation لەسەر Manga109.
نموونەی نوێ: [Manga109 panel/balloon/text YOLO26-seg](https://huggingface.co/ShadowB/Manga109-panel-balloon-text-yolov26-segmentation) —
box mAP@.5 = **٠٫٩٧٥**، mask mAP@.5 = **٠٫٩٧٠**.
**ڕێگای هەندەسی:** contour + بازنەی ڕەشی دەرەوە + پشکنینی گۆشە (باڵۆنی خڕ گۆشەکانی بەتاڵ دەهێڵێت، سندوقی چیرۆک پڕی دەکات).
لە توێژینەوەیەکدا (MDPI J. Imaging 2018) DeepLabv2 = **٪٨٩** و شێوازی کلاسیکی = **٪٥٠**، بەڵام تێکەڵکردنی هەردووکی باشترینە.
هەروەها: تێکست لە باڵۆن دەردەهێنرێت بە **adaptive threshold + dilation**، و دەبێت بازنەی باڵۆن mask بکرێت تا وەک نووسین نەخوێنرێتەوە.

---

## ٣. خوێندنەوە: ئەوەی جیاوازی دەکات

1. مۆدێلی تایبەت بە کۆمیک (`manga-ocr` بۆ ژاپۆنی، تێکست نەک دەق)، یان PaddleOCR؛ Tesseract تەنها fallback ە.
2. **٢× گەورەکردن پێش OCR** (`MT_UPSCALE = 2.0` لە پڕۆژەی عەرەبیدا) — نووسینی بچووک بەدەست دێت.
3. **دەقەکانی یەک باڵۆن بەیەک دەگەنەوە، پاشان وەرگێڕان** — ئەگەنا هەر پارچەیەک بە جیا وەرگێڕدرێت و ڕستە دەشکێت.
4. دەقی دەرەوەی باڵۆن (SFX، ناوی شوێن) بە جیا هەڵدەسەنگێنرێت؛ زۆربەیان **دەیهێڵنەوە** وەک خۆی.
5. فلتەری «بێبایەخ»: OCR بۆ شتێک وەک ڕوخسار یان جومگە دەدات، بۆیە دەبێت هەڵبژێردرێتەوە (دەق دەبێت پیتی هەبێت و لە باڵۆن بێت).

---

## ٤. سڕینەوە: هونەر نەمرێت

- باشترین: `lama_large` inpaint — بەڵام ٢ گێگابایتە و بۆ ئەندرۆید زۆر قورسە.
- مامناوەند: **تەنها پیکسلی نووسین بسڕەوە** (سیاو یان سپی، بەپێی پاشبنەما) و شوێنەکە بە ڕەنگی نزیک پڕ بکەرەوە — نەک هەموو سندوقەکە. ئەمە هونەری ژێر نووسین دەپارێزێت.
- لە `webtoon-translator` دا mask ی جومگەیی (dilated strokes) بەکاردێت بۆ ئەوەی چوارچێوەی پانێل لەناو نەچێت.

---

## ٥. کوردی: ئەوەی توێژینەوەکان دەیڵێن

**وەرگێڕان:** بۆ ئینگلیزی → کوردی ناوەندی، Google لە NLLB باشترە:

| ئاراستە | NLLB (BLEU / chrF2) | Google (BLEU / chrF2) |
|---|---|---|
| EN → CKB | ١٫٥ / ٢٥٫٥ | **٣٫٥ / ٣٣٫٦** |
| CKB → EN | ١١٫٤ / ٢٨٫٦ | **٢٢٫٤ / ٤٢٫٩** |

(pre/post-processing — پاککردنەوەی نیشانە، یەکخستنی پیت — هەردووکیان باشتر دەکات.)
سەرچاوە: [Language and Speech Technology for Central Kurdish Varieties](https://arxiv.org/pdf/2403.01983)، Table 5.

لێکۆڵینەوەیەکی تر: Google لە ڕووی مۆرفۆلۆژی و ڕێزمانی کوردی «باشە وەک ڕەشنووس»، بەڵام لە **ئیدیۆم و پەندەکان** و لە **کاتەکان** (future perfect, third conditional) شکست دەهێنێت.
سەرچاوە: [The Case of English–Sorani Kurdish Translation (Koya Univ.)](https://jhss.koyauniversity.org/index.php/jhss/article/download/655/183/3323).

واتە: ئەو کێشانەی کە ماوە، کێشەی **وەرگێڕان** نییە — کێشەی **خوێندنەوە**یە. Google بێ کلیل و بێ پارە ckb دەدات.

**نووسینەوە بە کوردی** (ئەمە جێیە کە زۆربەیان هەڵە دەکەن):
- فۆنتی ڕاستەقینەی ئارابیک-سکریپت (Noto / Rudaw) پێویستە؛ Arial/DejaVu پیتەکان دەکاتە پیتی جیاواز.
- **هەرگیز وشە بە پیت مەشکێنە** — پێویستە shaping جارێک بکرێت، نەک دوو جار (ئەگەنا وشە پێچەوانە دەنووسرێت).
- بەرزیی دێڕ بە ascent+descent، نەک guessed.
- ئەگەر وەرگێڕان نەگونجا، باڵۆن بەتاڵ بهێڵەرێتەوە (نەک سڕینەوە بێ نووسین).
- ڕەنگی نووسین لە ڕەنگی پاشبنەما وەربگیرێت: سپی لەسەر ڕەشی باڵۆنی تەقینەوە، ڕەش لەسەر سپی.

## ٦. ئێمە لە کوێداین

| پارچە | لە ئێمەدا | حاڵەت |
|---|---|---|
| دۆزینەوە | `comicTextLines` (ink + bubble contour) + ML Kit boxes | ✅ هەیە |
| خوێندنەوە | PP-OCRv6 tiny + latin (ONNX) + ML Kit | ✅ هەیە — **کێشەی سەرەکی لێرەیە** |
| کۆکردنەوەی باڵۆن | `inkGroups` + `mergeOcrLines` | ✅ هەیە |
| دەقی سپی لەسەر ڕەش | inverted pass (١٫٩٫٩) | ✅ هەیە |
| ٢× گەورەکردن بۆ نووسینی بچووک | `MAX_UPSCALE_READS` (١٫٩٫١٠) | ✅ هەیە |
| وەرگێڕان بە کوردی | Google endpoint ی بێ کلیل (`ckb`) | ✅ هەیە |
| نووسینەوە | فۆنتی Rudaw، RTL، shrink-to-fit | ✅ هەیە |
| مۆدێلی segmentation ی باڵۆن | کامۆدێکی ONNX ی `comic-text-detector` لە ئەپدایە، بەڵام بەکارنەهێنراوە | ⚠️ یەدەگ |
| inpaint | نییە (flat fill) | ⚠️ نەماوە |

## ٧. پلانی داهاتوو بێ هیچ API

1. **مۆدێلی segmentation بەکاربهێنە بۆ دۆزینەوە** لە جێی هەندەسی — ئەمە دەبێتە هۆی ئەوەی باڵۆنەکان کە ئێستا ناناسرێنەوە بدۆزرێنەوە.
2. سڕینەوەی جومگەیی (تەنها پیکسلی نووسین) بۆ دەقی سەر هونەر.
3. زنجیرەی فۆنتی fallback بۆ کوردی + پشکنینی shaping یەکجار.
4. گلۆسەری ناوەکان بۆ هەمان چیرۆک (ناوی کەسایەتییەکان هەمان شێوە بمێنن).

## ٩. ئەوەی لە [`s1po0/Kurd-man`](https://github.com/s1po0/Kurd-man) ەوە هێنرایە ئێرە

پڕۆژەی `Kurd-man` هەمان بیرۆکەی هەیە بەڵام بۆ کۆمپیوتەر (Python + Tesseract).
ئەو شتانەی کە بە سوودی خۆمان بوون و ئێستا لە ئەپدا هەن:

| بیرۆکە لە Kurd-man | جێبەجێکردن لە ئێمە |
|---|---|
| `_ocr_uncovered_bubbles`: هەر باڵۆنێک کە OCR ی گەورە لەدەستی داوە، بە جیا دەبڕدرێت، دەرەوەی کۆنتورەکە سپی دەکرێت، ٢–٣× گەورە دەکرێت، پاشان دەخوێندرێتەوە | `PaddleComicOcr` → قۆناغی `deep` (`MAX_DEEP_BUBBLES`) بە `ComicContour.maskedCrop` + `createScaledBitmap` |
| `_detect_bubble_candidates` + `_point_in_contour` (دەق دەبێت لەناو شێوەی باڵۆن بێت) | `ComicContour.containsInk` پشکنین لەسەر هەر دێڕێکی قۆناغی deep |
| زنجیرەی وەرگێڕەران: Google → MyMemory (کاتێک یەکەم شکست دەهێنێت) | `GoogleTranslateProvider` → `myMemoryOne` وەک یەدەگ |
| `dedupe_words` / یەک باڵۆن = یەک پارچە | `mergeOcrLines` + `inkGroups` (پێشتر هەبوو) |
| `shaping` تەنها بە یەک ڕێگا، فۆنتی ڕاستەقینەی عەرەبی، بێ □ | `TextPaint` + Rudaw/Noto (پێشتر هەبوو) |
| Cache ی SQLite: هەر ڕستەیەک تەنها جارێک | `TextCache` + Room (پێشتر هەبوو) |

ئەوەی هێشتا نەهاتووە: `NLLB` ی ئۆفلاین (٢.٥ گێگابایت — بۆ ئەندرۆید زۆر گەورەیە)، و `glossary.json`
(دەتوانرێت دواتر زیاد بکرێت بۆ ناوی کەسایەتییەکان).

## ١٠. یەدەگی «ڕێگای Kurd-man» (١٫٩٫١٤)

هەرگیز با پەڕەیەک بە ئینگلیزی نەمێنێت. دوای ئەوەی خشتە تایبەتەکە هەرچی توانی جێگیر کرد،
ئەپەکە هەمان شێوازی سادەی ئەپی Kurd-man بەکاردەهێنێت:

1. لاپەڕە دەبڕدرێت بە tiles ی ١٤٠٠px بە ٢٢٠px هەڵۆشاوە.
2. ML Kit دەق دەداتەوە (بێ هیچ مۆدێلی زیادە).
3. ئەو دێڕانەی دەکەونە سەر سنووری دوو tile (لە ناوەندی core نین) فڕێ دەدرێنەوە.
4. دێڕە دووبارەکان (IoU ≥ ٠٫٥٥) یەک دەکرێنەوە.
5. دێڕەکانی سەر یەک کەوتوو (بۆشایی ≤ بەرزی دێڕ) دەبن بە یەک ڕستە.
6. ئەو ڕستانە وەردەگێڕدرێن و دەنووسرێنەوە کە **هێشتا** نەنووسراون — بەسەر ئەوانەی پێشوو نانووسرێتەوە.

دەستکاری: `ManhwaFallback.kt` + `ImagePipeline.kt`، و `OnDeviceImageOcr.plainLines` بۆ دەستگەیشتن بە ML Kit.
